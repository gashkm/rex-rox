# REX ROX static website framework

A static, multi-page website for the 1727 VEX program REX ROX.

## Files
- `index.html` — semantic page structure
- `css/style.css` — layout, colors, and responsive behavior
- `js/main.js` — mobile navigation only
- `assets/images/` — all images

No framework, build step, or dependency required.

Hosted statically by Joseph Zhang (1727V/K).
